# Spring Boot WebSocket мини-чат

Простой backend-only учебный проект для знакомства с обычным WebSocket без STOMP. JavaScript-страница встроена в Spring Boot; отдельного frontend и базы данных нет. История сообщений хранится в памяти и ограничена последними 50 записями.

## Как работает

- Браузер открывает двустороннее соединение `ws://localhost:8080/ws`.
- Отправленный текст сервер рассылает всем подключённым клиентам.
- При подключении клиент получает системное сообщение и историю последних сообщений.
- В браузере используется нативный `WebSocket`; на backend — Spring `TextWebSocketHandler`.

Откройте страницу в нескольких вкладках, чтобы увидеть общую рассылку.

## Технологии

- Java 17, Spring Boot 3.4.3
- Spring WebSocket, без STOMP
- Gradle Kotlin DSL (`build.gradle.kts`)
- HTML/CSS/JavaScript и WebSocket API браузера
- Хранение активных подключений и истории в памяти

## Запуск

Требуются JDK 17+ и Gradle 8.x. В корне проекта:

```bash
gradle bootRun
```

Откройте http://localhost:8080. Откройте ещё одну вкладку и отправьте сообщение — оно появится во всех открытых чатах.

## Проверка без браузера

Установите `websocat` или `wscat`, затем подключитесь:

```bash
websocat ws://localhost:8080/ws
```

Текстовые сообщения, отправленные в соединение, будут разосланы всем подключённым участникам. История API доступна по адресу `http://localhost:8080/api/messages`.

## Важные отличия от SSE

WebSocket — двустороннее соединение: и браузер, и сервер могут отправлять данные по одному соединению. SSE передаёт поток только от сервера кл��енту. Этот пример рассчитан на один экземпляр приложения; память не разделяется между несколькими процессами и очищается после перезапуска.
